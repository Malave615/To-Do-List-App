## Project Overview

This mini project is a simple To-Do-List created using jQuery. The app allows users to manage their daily tasks by adding, deleting, marking items as complete, and reordering them.

## Features

**Feature #1:** User can add a new item to a list of items.

**Feature #2:** User can cross out an item as done.

**Feature #3:** User can delete an item from the list.

**Feature #4:** User can change the order of items on a list.

## Project Dependencies

**jQuery** Implemented with URL link to CDL
**jQuery UI** Used for drag and drop sorting (reordering items)
**CDL**

## Setup And Installation

1. Clone the Repository

   ```bash
   git clone https://github.com/Malave615/To-Do-List-App
   cd To-Do-List-App
   ```

2. **Open the App**
   Open the index.html file in your browser.

## Usage

- Type a task in the input field and click "Add" to include it in your list.
- Click on an item to mark it as complete (crossed out)
- Click the "X" button next to an item to delete it.
- Drag and drop items to rearrange their order.

## Testing

You can manually test the features of the app by interacting with the app in the browser. Since this is a front-end only project, there is no backend or automated testing.
